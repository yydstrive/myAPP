# 版本更新日志

本文件记录“日程清单”H5 与 Android App 的版本变化。除非另有说明，两个平台共用同一套页面和业务代码。

## 待发布

暂无。

## 1.0.2（版本号 102）— 2026-09-10

### 新功能

- 新建任务支持低、中、高三种优先级；默认为中优先级且不显示标签，低优先级显示橘色“低”标签，高优先级显示红色“高”标签。
- 优先级随任务写入本地持久化存储，同时完整保留 uniCloud 字段、云对象参数校验和数据库 Schema。
- 四张首页卡片与搜索、分类通用任务列表统一显示优先级标签；未完成卡片中的优先级标签紧靠逾期标签左侧。
- 任务保持原有日期排序，同一天内统一按高、中、低优先级排列。
- “本周逾期值”卡片支持点击打开“每周逾期值概览”：本周实时数据只在顶部显示，已结束周固化为本地历史记录，并展示相较前一周的变化天数与环比；减少显示绿色，增加显示红色。

### 界面与交互

- 逾期趋势弹窗移除右上角重复的关闭按钮，仅保留底部“关闭”按钮。
- 通用任务列表空状态及列表勾选标记改为纯 CSS 绘制，不再受手机系统字体和字号影响。
- 取消任务添加成功后的提示，所有轻提示统一使用无图标文字样式。
- 优先级选择器仅保留“低”和“高”按钮；未选择时即为默认中优先级，并放大按钮文字。
- 添加任务按钮的加号改为纯 CSS 绘制，避免受系统字体和字号影响。

### 修复

- 修复逾期历史弹窗误嵌套在日期弹窗内的问题，并增加两个弹窗互斥保护，避免同时打开。

### Android 安全与打包

- 使用 DCloud 安心云打包及原 DCloud 云端证书生成 Android 正式版 APK，包名保持为 `com.personal.daylist`，可覆盖安装 1.0.0 或 1.0.1 并保留应用本地数据。
- APK 的 v1、v2 签名均验证通过；签名证书 SHA-256 与 1.0.1 完全一致。
- 最终权限清单仅包含网络、网络状态以及 Android 自动生成的应用内部签名权限；网络权限继续为后续手动同步功能预留。
- 安装包文件名为 `dayList-1.0.2-release.apk`，SHA-256 为 `f21ebff948a84d3cec6dbcf61df33cf1d78606cd9058a965653c8c9e2beedd90`。

## 1.0.1（版本号 101）— 2026-09-03

### 修复

- 关闭页面下拉刷新，避免拖动卡片高度调节器时误触发刷新。
- 移除卡片高度的最大限制，仅保留最小高度限制；卡片内部仍支持独立滚动。
- “今日任务”完成数改为按实际完成日期统计：凡是在今天完成的任务都会计入，不再局限于原定今天的任务，因此允许显示 `2/1`、`3/1` 等结果。
- 统一 Android App 与 H5 的卡片任务数量及右侧箭头布局。
- 将卡片右侧箭头和日期选择器月份切换箭头改为纯 CSS 绘制，避免受到手机系统字体影响，并确保位于按钮圆形底色中央。

### Android 安全与打包

- 强制移除不需要的存储、设备信息、媒体读取、安装应用及厂商角标权限。
- 当前安装包只保留网络、网络状态以及 Android 自动生成的应用内部签名权限；网络权限为后续手动同步功能预留。
- 使用 DCloud 安心云打包及 DCloud 云端证书，APK 的 v1、v2 签名均验证通过。
- 包名和签名与 1.0.0 保持一致，可直接覆盖安装并保留本地任务数据。

### 数据与发布状态

- 任务继续保存在当前浏览器或 App 的本地持久化存储中。
- uniCloud 云对象、数据库及远程同步代码完整保留，`config/data-source.js` 中的 `REMOTE_SYNC_ENABLED` 默认保持为 `false`。
- H5 源码和生产构建已同步更新；本版本生成时未覆盖发布线上 H5 托管版本。

## 1.0.0（版本号 100）— 2026-09-03

### 首次发布

- 提供“未完成”“今天”“已完成”“未来”四类任务卡片，并支持卡片内部滚动。
- 支持按日期创建任务、月历选择日期、完成与取消完成，以及按日期规则自动移动任务分类。
- 支持关键词搜索、分类任务列表、修改任务文字、滑动删除、回收站恢复及永久删除。
- 支持任务日期标签、逾期天数标签和本周逾期值统计。
- 支持分别调整并保存上下两排任务卡片高度。
- 完成标记和主要图标使用 CSS 绘制，减少手机字体设置对界面的影响。
- Android App 默认采用设备本地持久化存储；远程同步代码通过代码级开关关闭。

## 升级注意事项

- 从 1.0.0 或 1.0.1 升级到 1.0.2 时请直接覆盖安装，不要先卸载旧版本，也不要在系统设置中清除应用数据。
- 卸载 App、清除应用数据或更换手机不会自动迁移本地任务；后续需要通过计划中的手动同步或导入导出功能完成迁移。
- 后续 Android 版本必须继续使用相同包名和签名证书，才能覆盖安装并保留已有本地数据。
